## 📊 BMI Categories

The calculator uses standard BMI ranges:

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obesity |

---

## 🧮 BMI Formula

BMI is calculated using the following formula:

```text
BMI = Weight (kg) / Height² (m)
```

For example:

```text
Height = 175 cm
Weight = 70 kg

Height = 1.75 m

BMI = 70 / (1.75 × 1.75)

BMI = 22.9
```

The result falls within the **Normal Weight** category.
